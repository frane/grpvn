# grpvn identity

The mark is a custom lowercase **g**: one continuous conversation loop and a
connected endpoint. Keep the silhouette intact at small sizes.

- `mark.svg` — transparent mark for light backgrounds.
- `icon.svg` — forest-green app icon with a light mark and mint endpoint.
- `logo.svg` — horizontal project lockup.

`icon.svg` is the editable source. Run `python3 scripts/generate-icons.py` on
macOS with `rsvg-convert` and `iconutil` to regenerate the shared web icon and
native PNG, ICO and ICNS assets, plus the transparent and light/dark logo variants. Generated assets are committed, so normal
builds require no graphics tools.

Original grpvn artwork, provided under the project's Apache 2.0 license.
